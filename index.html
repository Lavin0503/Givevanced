Features

Everything a giveaway needs, nothing it doesn't.

Set it up in one command. Givevanced handles entries, winners, claims and cleanup.

🔒

Entry requirements

Require roles, server boosting, the server tag, joining a partner server, or daily, weekly, monthly and total message counts. Add bypass roles for staff.

⚖️

Extra entries

Give boosters, supporters or any role more chances to win with weighted entries, like @Booster 5.

📬

DM claims

Winners are pinged in the channel and get a Claim button in their DMs. If their DMs are closed, the button appears in the channel.

🔁

Auto reroll

Set a claim time. Winners who don't claim in time are replaced automatically, and the giveaway shows who has claimed.

🏅

Winner roles & DM message

Hand out a role to every winner and send a custom DM with {prize} and {server} placeholders.

🎨

Fully customisable

Pick embed colours for live and ended states, add an image and thumbnail, choose the channel and set a different host.

How it works

Live in three steps.

No dashboard, no config files.

Add the bot

Invite Givevanced to your server and give it permission to send messages and embeds.

Run /giveaway create

Choose a duration, winners and prize. Add requirements and extras only if you want them.

Let it run

Members enter with one click. The bot ends it, pings winners and handles claims.

FAQ

Questions, answered.


Who can create giveaways?

Anyone with Manage Server, a manager role, or a creator role. Set the roles with /giveaway manager-roles and /giveaway creator-roles.

Is there a website dashboard?

Yes. Log in with Discord on the Dashboard to join giveaways, and if you manage a server you can create, edit, end, reroll and delete giveaways, see and remove participants, clone past giveaways, set manager and creator roles and view stats. Every giveaway embed also has a Website button that opens its page.

Can I add messages or get a DM when it ends?

Yes. When you create a giveaway you can set a start message and an end message (use {prize} and {winners} in it), and turn on dm-host to get a private summary with the winners and claims when it ends. /giveaway extend adds more time to a running giveaway in one step.

Can I pause a giveaway or reuse my settings?

Yes. /giveaway pause freezes the timer and stops new entries until you /giveaway resume. /template save keeps a giveaway's settings under a name, and /template use starts a new one from it. You can also start a quick drop where the first people to click win, and members can press the bell on a giveaway to get a DM when it ends.

Can a giveaway require joining another server?

Yes. Use the required-server option on /giveaway create (or pick it in the dashboard). Givevanced has to be in both servers. When someone clicks Enter, only they see a message with the server's icon and a Join button, and they're entered automatically the moment they join. If they leave that server later, they're removed from the giveaway, and anyone who left before the draw can't win. If Givevanced is ever removed from that server, the giveaway pauses and keeps its time until the bot is added back.

Can I schedule a giveaway for later?

Yes. Use /giveaway schedule with a start time like 2 hours or 1 day, plus the usual options. It starts by itself, and you can see or cancel scheduled ones with /giveaway scheduled and /giveaway unschedule. Commands that need a giveaway let you pick it from a list, so there's no need to copy message IDs.

Can I block someone from giveaways?

Yes. Use /blacklist add to stop a person from joining any giveaway in your server. They're removed from live giveaways straight away. You can also manage the blacklist from the Dashboard, and use /blacklist remove or /blacklist list.

Can I leave a giveaway after joining?

Yes. Click Enter again and the bot privately tells you that you already joined, with a button to leave.

What if a winner has DMs closed?

Givevanced posts the Claim button in the giveaway channel instead, and pings the winner there.

How do message requirements work?

The bot counts messages sent after it joins. Requirements can be daily, weekly, monthly or total.

Can I fix a giveaway that didn't end?

Yes. Run /giveaway fix with the giveaway message ID. You can also end, edit, reroll or delete it the same way.
